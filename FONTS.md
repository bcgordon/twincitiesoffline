# Fonts

The fonts in `site/fonts/` are the Latin subsets served by Google Fonts. They are stored here so the site makes no outside requests.

| File | Font | License |
|---|---|---|
| `bricolage-grotesque.woff2` | Bricolage Grotesque (variable, 400–800) | SIL Open Font License 1.1 |
| `archivo-800.woff2` | Archivo 800 | SIL Open Font License 1.1 |
| `ibm-plex-mono-400.woff2`, `ibm-plex-mono-600.woff2` | IBM Plex Mono | SIL Open Font License 1.1 |
| `special-elite-400.woff2` | Special Elite | Apache License 2.0 |

American Typewriter is not included; visitors whose devices have it (Apple devices) see it, and everyone else sees Special Elite.
